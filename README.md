# Kichik Tabib — Face ID va Oylik Tizimi

Kichik Tabib klinika/korxonasi uchun Face ID, davomat va oylik hisob-kitob dasturi.

## Imkoniyatlar:
- Ish vaqti: 09:00 dan 17:00 gacha
- 09:00 dan oldin har 1 min erta kelsa: +1 000 so'm/min bonus
- 09:01–09:10 oralig'ida: 0 so'm (jarima yo'q)
- 09:10 dan kech qolsa: -1 000 so'm/min jarima
- Ishga umuman kelmasa: -150 000 so'm jarima
- 17:00 dan keyin ortiqcha ishlasa: +1 000 so'm/min qo'shimcha bonus
- Telegram Bot (@faceid_kichiktabibbot) orqali guruhga Face ID rasmlari bilan xabarnoma boradi
- WebApp / Mini App (mobil Android telefonlar uchun moslashgan)
- Alohida Admin panel (`/admin`)

## Ishga tushirish (Local):
```bash
npm start
```
Browserda ochish:
- Xodim Mini App: `http://localhost:3000`
- Admin panel: `http://localhost:3000/admin`
